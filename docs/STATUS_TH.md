# สถานะโปรเจกต์

อัปเดตจากโค้ด เอกสาร และไฟล์ผลลัพธ์ที่มีใน repository ณ วันที่ 24 ตุลาคม 2026

## สรุปสั้น ๆ

โปรเจกต์มีระบบจับคู่โปรไฟล์และมีผลทดลองแล้ว ตอนนี้ยังไม่ได้กำลัง train model หรือ build ระบบ สิ่งที่ค้างอยู่คือการจัดระเบียบไฟล์และตรวจการเปลี่ยนแปลงใน Git

## ความคืบหน้า

| งาน | สถานะ | หมายความว่า |
|---|---|---|
| ระบบหลัก | มีโค้ดครบตามขั้นตอน | เตรียมข้อมูล → จับคู่ → ประเมิน → รวมเป็นข้อมูลลูกค้า |
| ผลทดลอง R0–R6 | มีรายงานและไฟล์ผลแล้ว | R3 มี test F1 สูงสุดเฉพาะในชุดนี้ ไม่ใช่ผลดีที่สุดของทุกการทดลอง |
| นำ R3 ไปใช้ในระบบหลัก | ยังไม่ได้ทำ | ระบบหลักยังใช้โมเดลและเกณฑ์ตัดสินชุดเดิม |
| ทดลอง R6 เพื่อหาคู่ที่ระบบเดิมพลาด | ทดลองแล้ว แต่ยังไม่สำเร็จ | กู้คู่ที่พลาดได้ 3 จาก 3,316 คู่ จึงยังไม่ควรนำไปใช้ |
| ทดลองวิจัยรอบใหม่ (Phase 2) | ยังไม่เริ่ม | ผลตรวจ Phase 1 ผ่านบางส่วน; ต้องแก้เงื่อนไขก่อนเริ่มรัน |
| จัดระเบียบไฟล์ | มีการเปลี่ยนแปลงค้างใน Git | ยังไม่ได้ตรวจรับหรือ commit; ไฟล์ที่ลบใน Git ยังเรียกคืนได้ก่อน commit |
| กำลัง train/build อยู่ | ไม่พบว่ากำลังทำงาน | ตรวจดูโปรเซสที่ทำงานอยู่แล้ว ไม่พบงานของโปรเจกต์ |

## แปลคำว่า “ถึงไหนแล้ว”

ถ้าหมายถึง **ตัวระบบ**: มีโค้ดระบบหลักและผลทดลองเดิมแล้ว แต่ผลทดลองแต่ละชุดวัดคนละขอบเขต งานวิจัยรอบใหม่ยังต้องแก้ข้อมูล วิธีแบ่งชุด และวิธีประเมินก่อนรัน ดู [ผลตรวจความพร้อม Phase 1](research_rebuild/phase_01/06_PHASE_1_READINESS_GATE.md)

ถ้าหมายถึง **การจัดไฟล์**: มีการเปลี่ยนแปลงจำนวนมากใน working tree แต่ยังไม่ใช่การ build โปรแกรม และยังไม่ผ่านการตรวจรับ การลบที่เห็นใน `git status` เป็นการลบจาก working tree; ไฟล์ยังอยู่ใน Git history จนกว่าจะ commit การลบนั้น
