รูปที่ 3.5 การแปลงคู่โปรไฟล์เป็นเวกเตอร์ฟีเจอร์หนึ่งแถว

แสดงลำดับการประมวลผลจากโปรไฟล์สองฝั่งของคู่ข้อมูล ไปสู่การคำนวณหลายมิติ เช่น string similarity, semantic similarity, set overlap, image statistics และ cross-modal context จากนั้นรวมผลเป็นเวกเตอร์ฟีเจอร์หนึ่งแถวต่อหนึ่งคู่ข้อมูล ก่อนส่งเข้าสู่แบบจำลองเพื่อใช้ในการฝึกหรือทำนายผล
